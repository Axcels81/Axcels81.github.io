## Tentang

Satu halaman untuk memperkenalkan diri, keahlian, proyek, dan kontak. Bertema *pixel* dengan mode gelap/terang, dan daftar repositori GitHub yang tampil otomatis.

## Isi halaman

- **About** — profil singkat dan biodata
- **Skills** — HTML, CSS, JavaScript, React Native, PHP, Python, SQL, Figma, Git, VS Code
- **Projects** — proyek pilihan + repositori GitHub (otomatis)
- **Certificates** — sertifikat yang dimiliki
- **Contact** — email, LinkedIn, GitHub

## Teknologi

HTML · CSS · JavaScript — satu file `index.html`, tanpa framework atau proses build. Di-host gratis di **GitHub Pages**.

## Menjalankan di lokal

Cukup buka `index.html` di browser. Tidak perlu server.
